# Doraemon World — Website tĩnh

Website fan-made giới thiệu Doraemon, bảo bối, bạn bè và một mini quiz. Giao diện responsive cho máy tính và điện thoại.

## Cấu trúc thư mục

```text
doraemon_website/
├── index.html
├── README.md
├── assets/
│   └── mascot.svg
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Cách chạy

1. Giải nén `doraemon_website.zip`.
2. Mở thư mục.
3. Nhấp đúp `index.html` để mở bằng Chrome, Edge hoặc Firefox.

Không cần cài Node.js hay chạy server. Font chữ lấy từ Google Fonts; nếu mất mạng, website vẫn chạy với font hệ thống.

## Tùy chỉnh

- Sửa nội dung trong `index.html`.
- Sửa màu sắc, bố cục trong `css/style.css`.
- Sửa tương tác, câu đố trong `js/script.js`.
- Thay hình minh họa trong `assets/mascot.svg`.

Đây là dự án fan-made, không phải trang web chính thức. Doraemon và các nhân vật thuộc về chủ sở hữu bản quyền tương ứng.
